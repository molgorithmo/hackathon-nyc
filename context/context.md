# Project Context

## Goal

Build **Fax to Fill** for PillSpark: turn a blurry or handwritten prescription fax into a structured draft order while surfacing uncertainty for pharmacist review.

## Core product principle

The system must never silently guess. Every extracted field should include its source evidence, confidence, status, and possible alternatives. Critical ambiguity must block approval.

## Planned workflow

1. Receive a prescription image or PDF.
2. Clean the image with deskewing, denoising, sharpening, and contrast adjustment.
3. Extract text and locations with baseline OCR.
4. Use a vision model to produce structured prescription candidates.
5. Validate drug names, strengths, required fields, and internal consistency.
6. Send uncertain fields to pharmacist review.
7. Produce verified JSON with corrections and an audit trail.

## Current technical direction

- Frontend: Vite, React, and TypeScript scaffold initially generated by Ninoo.
- Image preprocessing: OpenCV.
- Baseline OCR: PaddleOCR.
- Structured extraction: a vision-capable model accessed through Nicrron.
- Decision layer: the deterministic release gate owns acceptance; Jev is optional future exception classification, accepts text/JSON, and cannot read images or select ambiguous drug/dose values.
- Initial data: ten unchanged ClinOCR evaluation images for OCR and non-prescription rejection tests. ClinOCR is synthetic and these examples are not prescription orders.
- Additional data: RxHandBD Zenodo v1, 5,578 unchanged handwritten word crops with upstream labels (4,463 train / 1,115 test), for OCR evaluation only. Imported separately under `data/rxhandbd/`; a frozen 100-crop recognition benchmark is complete, not full prescription/fax evaluation.
- Observability and evaluation: PRISM guardrail, evaluator, trace, and grounded knowledge base where useful.

## Demo target

- Clear prescription: extract and approve quickly.
- Ambiguous prescription: detect a critical conflict such as `25 mg` versus `75 mg`, block approval, require pharmacist resolution, and record the correction.
